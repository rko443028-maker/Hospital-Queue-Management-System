# Hospital Queue Management System

## Project Overview
The Hospital Queue Management System is a menu-driven application developed using Python for a Python Programming Lab Project Based Learning (PBL) assignment.

## Features
- Register normal patients
- Register emergency patients with High, Medium, and Low priority
- Serve emergency patients before normal patients
- Manage normal patients using the First In, First Out (FIFO) principle
- View waiting queues
- Search waiting patients by ID or name
- Validate user input

## Technologies Used
- Python 3
- Classes and objects
- Lists and `collections.deque`
- Functions, loops, and conditional statements
- Exception handling

## How to Run
1. Install Python 3 on your computer.
2. Download `hospital_queue_management.py`.
3. Open Command Prompt or a terminal in the folder containing the file.
4. Run:

   ```bash
   python hospital_queue_management.py
   ```

   On some Windows computers, use `py hospital_queue_management.py` instead.

## Project Files
- `hospital_queue_management.py` — Python source code
- `Hospital_Queue_Management_System_PBL_Report.pdf` — PBL report

## Important Note
This is an educational demonstration, not a real clinical triage system. Patient data is stored in memory and is cleared when the program exits. Emergency priority selection in this project must not be used to make real medical decisions.
